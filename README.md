# Greetings, Artist.
I am pleased to present you the **Architect's Optimization Mod**, a small performance-oriented mod for BreakArts 3.
You will feel the most improvement around the main menu area. It may not do wonders for you, but it certainly helps get the game running!
It also extends the boundaries of the machine designer camera.

# Installation Guide

### 1. Install BepInEx 6.
> Download a __specific__ [BepInEx build](https://builds.bepinex.dev/projects/bepinex_be/755/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.755%2B3fab71a.zip) and unzip the contents directly inside the game folder.

### 2. Install the mod.
> Download the the [latest ZIP file from GitHub releases](https://github.com/Merilax/ArchitectsPerformanceMod/releases/tag/v1.0.0). Inside there will be a single DLL file. Unzip it and place it in `Break Arts III\BepInEx\plugins\ArchitectsPerformanceMod.dll`.

### 3. Run the game!
> The first time you start the game after installing BepInEx, or when the game updates, it will generate some necessary files for mods to function.
> This may take a minute, so __please be patient__.
> You will know the mod was installed correctly if you see the mod's name in the bottom left corner after the game has finished loading.

# Frequently Asked Questions:
### Why is the mod not doing anything?
> - Verify that the mod was installed. You will see its signature in the main menu, in the bottom left corner.
> - The mod won't do anything by default. Please enter the settings (just like usual) and configure it there.
> - If neither of these options apply to your case, please check the console for errors regarding this mod. You will probably have to send me the game logs so I can figure what went wrong.
### What does the "Overdrive" preset do?
> It just sets every option to it's lowest value. I got a little too excited with the naming.
